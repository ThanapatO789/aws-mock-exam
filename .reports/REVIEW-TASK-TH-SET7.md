# Review task: Thai explanations, reading guides and tags for Set 7 (ids 392–456)

You are reviewing newly written study material for AWS Certified Solutions Architect – Associate (SAA-C03) questions. A learner sees it right after answering, so a wrong or misleading statement teaches the wrong thing. The exam is in 9 days.

The material is in the file named in the prompt. For each question it contains the question, the choices, the KEY (already verified by three-way review; challenge it only if you are sure), the Thai explanation (`TH`), the reading guide (`ANALYSIS`: phrases highlighted in the question plus a note) and the topic `TAG`. Read only that file. Do not run commands and do not modify any files.

## Checkpoints (per question)
1. **Right answer**: the options under "ตัวเลือกที่ถูก" are exactly the KEY options.
2. **Technical accuracy**: every AWS claim in TH and in the ANALYSIS note is correct as of today. Flag anything false, outdated or overstated (service limits, defaults, renamed or retired services).
3. **Wrong-option reasoning**: each wrong option gets a reason, and the reason is valid.
4. **Key takeaway**: the `**จุดจำ: ...**` line is accurate and is the point that actually decides the question.
5. **Reading guide**: the highlighted phrases are the ones that decide the answer, and the note is correct.
6. **Tag**: cat/sub/pillar/domain fit what the question really tests. Flag only clear mismatches.
7. **Thai quality**: flag only wording that is confusing or ambiguous, not stylistic preference. AWS names stay in English.

## Output (markdown)
- `## Errors`: issues that must be fixed: `- <id>: <what is wrong> → <the correct statement>`. Quote the Thai phrase in question.
- `## Weak spots`: lower-priority issues, same format.
- `## Verdict`: one line, with how many are fine as-is.

Be specific and terse. Don't list questions with no issues.
