# Tech Talk

เมื่อคุณได้เรียนรู้วิธีใช้ container และบริการที่ช่วยรองรับการ implement container บนโครงสร้างพื้นฐาน AWS แล้ว คุณก็พร้อมเริ่มต้น architect แอปพลิเคชันด้วย microservices ได้ นี่คือการปิดท้ายเนื้อหาของโมดูลนี้ ต่อไปจะมี Knowledge Check สั้น ๆ

โมดูลถัดไปคือ Networking-2 ซึ่งเป็นการต่อยอดจากโมดูลก่อนหน้าคือ Networking-1

## Key terms
- Tech Talk: ช่วงสรุปเนื้อหาแบบพูดคุยโดยผู้สอน ปิดท้ายก่อนเข้าสู่ Knowledge Check ของโมดูล
