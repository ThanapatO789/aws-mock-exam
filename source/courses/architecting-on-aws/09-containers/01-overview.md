# Overview

โมดูลนี้แนะนำการ architect แอปพลิเคชันแบบ microservices คุณจะได้เรียนรู้เกี่ยวกับ containers และบริการของ AWS ที่รองรับ microservice architecture

ในโมดูลนี้ คุณจะได้เรียนรู้วิธี:

- อธิบายประโยชน์ของ microservices ในฐานะกลยุทธ์ decoupling ที่มีประสิทธิภาพ เพื่อขับเคลื่อนแอปพลิเคชันที่มี high availability ในระดับสเกลใหญ่
- ระบุว่า AWS container services ใดที่รองรับแอปพลิเคชันแบบ containerized บนคลาวด์

## Key terms
- Microservices: แนวทางสถาปัตยกรรมที่ออกแบบซอฟต์แวร์เป็นกลุ่มของ service ย่อยที่ทำงานอิสระต่อกัน
- Container: หน่วยบรรจุ (logical unit) สำหรับแพ็กเกจ microservices ของแอปพลิเคชัน
