# Knowledge Check

แบบทดสอบท้ายโมดูล ใช้ทบทวนความเข้าใจเนื้อหาทั้งหมดของโมดูล 10 (Networking-2) ผลลัพธ์ที่ได้จะช่วยชี้ให้เห็นหัวข้อที่ควรกลับไปทบทวนเพิ่มเติม ประกอบด้วยคำถาม 3 ข้อ ดังนี้ (คำตอบที่ถูกต้องยืนยันจากระบบหลังตอบจริง)

## คำถามที่ 1

**คำถาม:** การเชื่อมต่อกับ transit gateway เรียกว่าอะไร
(What is a connection to a transit gateway called?)

- Virtual Private Network (VPN)
- **Attachment** ✅ (คำตอบที่ถูกต้อง)
- Route
- Virtual Private Cloud (VPC)

## คำถามที่ 2

**คำถาม:** องค์ประกอบของ AWS Site-to-Site VPN connection คืออะไร (เลือก 2 ข้อ)
(What are the components of an AWS Site-to-Site VPN connection? Select TWO.)

- **Customer gateway device** ✅ (คำตอบที่ถูกต้อง)
- Interface endpoint
- **Virtual private gateway** ✅ (คำตอบที่ถูกต้อง)
- Virtual Private Cloud (VPC) peering connection
- Gateway endpoint

## คำถามที่ 3

**คำถาม:** ข้อใดเป็นจริงเกี่ยวกับ Virtual Private Cloud (VPC) peering connection (เลือก 2 ข้อ)
(What is TRUE about Virtual Private Cloud (VPC) peering connections? Select TWO.)

- Connections are one-to-many.
- **Connections are one-to-one.** ✅ (คำตอบที่ถูกต้อง)
- Connections require a transit gateway.
- **Connections can span accounts.** ✅ (คำตอบที่ถูกต้อง)
- Connections are transitive.

หลังจากทำแบบทดสอบเสร็จ จะมีวิดีโอสรุปท้ายโมดูล (ความยาวประมาณ 5 นาที 8 วินาที) ปิดท้ายเนื้อหาเรื่อง VPC endpoints, VPC peering, hybrid networking และ AWS Transit Gateway ก่อนเข้าสู่โมดูลถัดไป

## Key terms
- Knowledge Check: แบบทดสอบสั้น ๆ ท้ายโมดูลเพื่อประเมินความเข้าใจ
