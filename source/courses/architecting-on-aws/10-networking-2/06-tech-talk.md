# Tech Talk

บทเรียนนี้เป็นวิดีโอ tech talk สรุปเนื้อหาของโมดูล (ความยาว 2 นาที 22 วินาที) ไม่มีเนื้อหาข้อความเพิ่มเติมนอกจากวิดีโอ

บทสรุปจากวิดีโอ: จบการทบทวนเชิงลึกเรื่อง networking สำหรับ cloud infrastructure จากนั้นให้ทำ Knowledge Check สั้น ๆ เพื่อประเมินสิ่งที่ได้เรียนรู้

## Key terms
- Tech Talk: บทเรียนวิดีโอสรุปเนื้อหา ไม่มีข้อความเพิ่มเติมนอกวิดีโอ
