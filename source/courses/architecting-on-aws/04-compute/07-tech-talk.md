# Tech Talk

บทเรียนนี้เป็นวิดีโอ instructor-led (ความยาวประมาณ 6 นาที 12 วินาที) ที่พาผู้เรียนดูตัวอย่างการปฏิบัติจริงเกี่ยวกับหัวข้อในโมดูลนี้ ไม่มีเนื้อหาข้อความเพิ่มเติมนอกจากวิดีโอ

หลังจบเนื้อหาในโมดูลนี้ ผู้เรียนได้เรียนรู้แง่มุมต่าง ๆ ของบริการ compute บน AWS infrastructure ครบถ้วนแล้ว ลำดับถัดไปคือ Knowledge Check และแบบฝึกหัด lab

โมดูลถัดไปจะอธิบายวิธี implement storage ในแอปพลิเคชัน

## Key terms
- Tech Talk: บทเรียนวิดีโอสาธิต/สนทนาเชิงลึกโดย instructor ท้ายโมดูล ก่อนเข้าสู่ Knowledge Check
