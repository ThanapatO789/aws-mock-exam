# Overview

โมดูลนี้ให้ภาพรวมของบริการด้าน compute ต่าง ๆ บน AWS โดยสำรวจบริการ compute หลายประเภทและความเกี่ยวข้องกับ use case ของแอปพลิเคชันต่าง ๆ

หลังจบโมดูลนี้ ผู้เรียนจะสามารถ:

- ระบุรายชื่อบริการ compute ของ AWS
- อธิบายสิ่งที่ต้องพิจารณาเมื่อ deploy เซิร์ฟเวอร์ใหม่และเซิร์ฟเวอร์เดิมไปยัง **Amazon Elastic Cloud Compute (Amazon EC2)**
- ระบุประเภท volume ที่ควรแนบกับ EC2 instance ตาม use case ที่กำหนด
- อธิบายตัวเลือกด้านราคา (pricing options) ของ Amazon EC2
- อธิบายประโยชน์ของ **AWS Lambda**

## Key terms
- Amazon EC2 (Elastic Cloud Compute): บริการ virtual server (compute) หลักของ AWS
- AWS Lambda: บริการ serverless compute ของ AWS
