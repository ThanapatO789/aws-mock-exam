# Tech Talk

บทเรียนนี้เป็นวิดีโอสนทนา (tech talk discussion) ระหว่างผู้สอนสองท่าน พูดคุยเกี่ยวกับหัวข้อ **account security** เพื่อสรุปและเสริมความเข้าใจเนื้อหาที่ผ่านมาในโมดูลนี้ (ความยาววิดีโอประมาณ 4 นาที 46 วินาที) เนื้อหาในวิดีโอเป็นการสนทนาเสริม ไม่มีเนื้อหาข้อความสรุปเพิ่มเติมนอกวิดีโอในหน้านี้

หลังจบบทเรียนนี้จะเข้าสู่ **Knowledge Check** ท้ายโมดูล

## Key terms
- Tech Talk: บทเรียนรูปแบบวิดีโอสนทนาระหว่างผู้สอน เพื่อทบทวนและเสริมเนื้อหาของโมดูล
