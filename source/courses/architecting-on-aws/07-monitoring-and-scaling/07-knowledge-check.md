# Knowledge Check

ใช้ Knowledge Check นี้เพื่อทบทวนแนวคิดจากโมดูลนี้ ผลลัพธ์อาจช่วยระบุหัวข้อที่ควรทบทวนเพิ่มเติม (ตอบและ submit จริงในระบบเพื่อยืนยันคำตอบที่ถูกต้อง)

## คำถามที่ 1

**Which of these is a valid target for an Application Load Balancer?**
(อะไรคือ target ที่ใช้ได้กับ Application Load Balancer)

- An Amazon Elastic Compute Cloud (Amazon EC2) instance ✅ (ถูกต้อง)
- An Availability Zone
- An Amazon Simple Storage Service (Amazon S3) bucket
- A virtual private network (VPN) connection

## คำถามที่ 2

**You have an application with unpredictable traffic patterns that runs on at least two instances. You want the CPU utilization to stay at about 75 percent. Which Amazon EC2 Auto Scaling strategy should you choose?**
(มีแอปพลิเคชันที่มี traffic pattern ไม่แน่นอน รันบน instance อย่างน้อย 2 ตัว ต้องการให้ CPU utilization อยู่ที่ประมาณ 75 เปอร์เซ็นต์ ควรเลือกกลยุทธ์ Amazon EC2 Auto Scaling แบบใด)

- Scheduled
- Predictive
- Dynamic ✅ (ถูกต้อง)
- Manual

## คำถามที่ 3

**What service can invoke actions based on data from account resources and supported third-party management services?**
(บริการใดสามารถเรียกใช้ actions ตามข้อมูลจากทรัพยากรในบัญชีและบริการจัดการของบุคคลที่สามที่รองรับได้)

- Amazon CloudWatch Logs
- Amazon EventBridge ✅ (ถูกต้อง)
- AWS CloudTrail
- Amazon EC2 Auto Scaling

## คำถามที่ 4

**Which of the following are valid alarm states in Amazon CloudWatch? (Select TWO.)**
(ข้อใดต่อไปนี้เป็นสถานะ alarm ที่ถูกต้องใน Amazon CloudWatch — เลือก 2 ข้อ)

- READY
- ALERT
- ALARM ✅ (ถูกต้อง)
- INSUFFICIENT DATA ✅ (ถูกต้อง)
- FAILED

## คำถามที่ 5

**Which of the following are use cases for AWS CloudTrail data? (Select TWO.)**
(ข้อใดต่อไปนี้เป็น use case ของข้อมูล AWS CloudTrail — เลือก 2 ข้อ)

- Provide real-time observability of AWS resources.
- Store log data as a record of account usage. ✅ (ถูกต้อง)
- Log events for a particular service or application.
- Capture root login failures. ✅ (ถูกต้อง)
- Collect metric data measuring CPU utilization.
