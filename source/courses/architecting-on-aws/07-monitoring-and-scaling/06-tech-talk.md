# Tech Talk

บทเรียนนี้เป็นวิดีโอพูดคุยสรุปจากวิทยากร (video duration 7 นาที 10 วินาที) ไม่มีเนื้อหาข้อความเพิ่มเติมนอกจากบทสรุปสั้นๆ ต่อไปนี้:

Load balancing และ auto scaling เป็นคุณสมบัติที่สามารถทำได้ก็ต่อเมื่อใช้ cloud infrastructure เท่านั้น ใช้คุณสมบัติเหล่านี้เพื่อสร้างแอปพลิเคชันที่ scale ได้สูงและมี availability สูง นี่คือการสรุปเนื้อหาเรื่อง Monitoring and Scaling

ขั้นตอนถัดไป: ฝึกปฏิบัติจริงใน lab และทดสอบความเข้าใจด้วย Knowledge Check

## Key terms
- ไม่มีคำศัพท์ใหม่เพิ่มเติมในบทเรียนนี้ (เป็นบทสรุปเนื้อหาของ load balancing และ auto scaling จากบทเรียนก่อนหน้า)
