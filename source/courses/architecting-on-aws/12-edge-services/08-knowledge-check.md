# Knowledge Check

ใช้ Knowledge Check นี้เพื่อทบทวนแนวคิดจากโมดูลนี้ ผลลัพธ์อาจช่วยระบุหัวข้อที่ควรทบทวนเพิ่มเติม (คำตอบที่ถูกต้องยืนยันจากระบบหลังตอบจริงในเบราว์เซอร์)

## คำถามที่ 1

**คำถาม (EN):** What are the potential benefits of implementing a Amazon CloudFront distribution? (Select TWO.)

**คำแปล:** ข้อใดคือประโยชน์ที่เป็นไปได้ของการติดตั้ง Amazon CloudFront distribution (เลือก 2 ข้อ)

ตัวเลือก:
- **Increased application security** ✅ ถูกต้อง
- Two global static IP addresses
- Automatic redundancy for all application content
- **Reduced latency for access to application content** ✅ ถูกต้อง
- On-premises data caching

## คำถามที่ 2

**คำถาม (EN):** Which of the following services offer DDoS protection? (Select TWO.)

**คำแปล:** ข้อใดต่อไปนี้เป็นบริการที่ให้การป้องกัน DDoS (เลือก 2 ข้อ)

ตัวเลือก:
- AWS Outposts
- Amazon Elastic Cloud Compute (Amazon EC2)
- Network Load Balancer
- **AWS Shield** ✅ ถูกต้อง
- **AWS WAF** ✅ ถูกต้อง

## คำถามที่ 3

**คำถาม (EN):** A network engineer wants to route 80 percent of web traffic to the ap-southeast-2 Region. The remaining 20 percent of traffic will be directed to the eu-west-1 Region. Which Amazon Route 53 routing policy is the best choice for this use case?

**คำแปล:** วิศวกรเครือข่ายต้องการ route web traffic 80% ไปยัง Region ap-southeast-2 ส่วนที่เหลืออีก 20% ไปยัง Region eu-west-1 ควรใช้ Route 53 routing policy แบบใดจึงจะเหมาะสมที่สุด

ตัวเลือก:
- Simple routing
- **Weighted routing** ✅ ถูกต้อง
- Geoproximity routing
- Geolocation routing
- Multivalue answer routing

## คำถามที่ 4

**คำถาม (EN):** What is a benefit of choosing AWS Outposts servers when compared to an Outposts rack?

**คำแปล:** ข้อใดคือประโยชน์ของการเลือกใช้ AWS Outposts servers เมื่อเทียบกับ Outposts rack

ตัวเลือก:
- More AWS services are available on Outposts servers
- Pool compute and storage capacity between multiple Outposts servers
- **A smaller-sized device can be placed in your own rack** ✅ ถูกต้อง
- You don't need to host your Outposts servers in a data center

ผลลัพธ์: ตอบถูกทั้ง 4 ข้อ (ยืนยันโดยการ submit จริงในเบราว์เซอร์)

หลังจากทำแบบทดสอบเสร็จ จะมีวิดีโอสั้น ๆ (ความยาวประมาณ 7 นาที 12 วินาที) ปิดท้ายโมดูล

## Key terms
- Knowledge Check: แบบทดสอบสั้น ๆ ท้ายโมดูลเพื่อประเมินความเข้าใจ
