# Tech Talk

บทเรียนสั้น ๆ นี้เป็นวิดีโอ tech talk (ความยาวประมาณ 3 นาที 16 วินาที) สรุปแนวคิดว่าใช้ **AWS Outposts** เพื่อตอบสนองความต้องการด้าน residency และ latency ของแอปพลิเคชัน ซึ่งเป็นการปิดท้ายเนื้อหาโมดูล edge services

ต่อจากนี้ ผู้เรียนจะได้ทำ Knowledge Check สั้น ๆ เพื่อประเมินสิ่งที่เรียนรู้มา จากนั้นจึงทำแล็บเพื่อนำแนวคิดที่เรียนในโมดูลนี้ไปใช้จริง

## Key terms
- Tech Talk: วิดีโอสรุปท้ายโมดูลโดยผู้สอน เชื่อมโยงเนื้อหาทั้งหมดของโมดูลเข้าด้วยกัน
