# Tech Talk

บทเรียนนี้เป็นวิดีโอ Tech Talk (ความยาวประมาณ 10 นาที 50 วินาที) ที่ instructor พูดคุยเจาะลึกเกี่ยวกับหัวข้อ automation เพิ่มเติม เพื่อสรุปเนื้อหาของโมดูล automation ในการสร้างและจัดการ cloud infrastructure จากนั้นจะเข้าสู่ knowledge check ท้ายโมดูล และในโมดูลถัดไปจะเรียนรู้เกี่ยวกับการ deploy application ด้วย container

## Key terms
- Tech Talk: บทเรียนวิดีโอเสริมท้ายโมดูล ที่ instructor พูดคุยเจาะลึกเกี่ยวกับหัวข้อของโมดูลนั้น ๆ
