# Knowledge Check

แบบทดสอบท้ายโมดูล ใช้ทบทวนความเข้าใจเนื้อหาทั้งหมดของโมดูล 8 (Automation) ผลลัพธ์ที่ได้จะช่วยชี้ให้เห็นหัวข้อที่ควรกลับไปทบทวนเพิ่มเติม ประกอบด้วยคำถาม 2 ข้อ ดังนี้ (คำตอบที่ถูกต้องยืนยันจากระบบหลังตอบจริง)

## คำถามที่ 1

**คำถาม:** AWS CloudFormation stack คืออะไร
(What is a AWS CloudFormation stack?)

- **All of the provisioned resources defined in a CloudFormation template** ✅ (คำตอบที่ถูกต้อง)
- All of the resources identified as drifted in a CloudFormation template
- A condition when resources are added on top of each other
- The properties of a single resource

## คำถามที่ 2

**คำถาม:** ข้อใดคือประโยชน์ของการใช้ AWS Cloud Development Kit (AWS CDK) ร่วมกับ AWS CloudFormation (เลือก 2 ข้อ)
(Which of the following are benefits of using AWS Cloud Development Kit (AWS CDK) with AWS CloudFormation? Select TWO.)

- **Developers can use common programming languages.** ✅ (คำตอบที่ถูกต้อง)
- Bulk discounts are automatically applied to resource usage.
- **Developers can call preconfigured resources with proven defaults.** ✅ (คำตอบที่ถูกต้อง)
- Components are limited to a single user.
- Using AWS CDK does not require an AWS account or credentials.

หลังจากทำแบบทดสอบเสร็จ จะปิดท้ายเนื้อหาโมดูล automation เรื่องการสร้างและจัดการ cloud infrastructure ก่อนเข้าสู่โมดูลถัดไปเรื่อง containers

## Key terms
- Knowledge Check: แบบทดสอบสั้น ๆ ท้ายโมดูลเพื่อประเมินความเข้าใจ
- CloudFormation stack: กลุ่มของ resource ทั้งหมดที่ provisioned ตามที่ define ไว้ใน CloudFormation template
