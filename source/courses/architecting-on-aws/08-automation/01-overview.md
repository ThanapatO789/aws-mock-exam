# Overview

โมดูลนี้แนะนำการทำ automation ในการ launch โครงสร้างพื้นฐาน AWS Cloud สำหรับ cloud application ของคุณ โดยจะเรียนรู้เกี่ยวกับบริการ AWS ที่ใช้ในการ automate การ launch cloud infrastructure

ในโมดูลนี้ คุณจะได้เรียนรู้วิธี:

- ใช้ **AWS CloudFormation** เพื่อ automate การ deploy infrastructure
- ระบุเครื่องมือที่ช่วย automate การ deploy infrastructure และช่วยจัดการ resource หลังจาก deploy แล้ว

## Key terms
- AWS CloudFormation: บริการสำหรับ automate การสร้างและจัดการ infrastructure บน AWS ผ่าน template (Infrastructure as Code)
