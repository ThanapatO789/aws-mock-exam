# AWS Services

บทเรียนนี้แนะนำ **AWS services** และหมวดหมู่บริการ (service categories) ต่าง ๆ ที่นำมาใช้ในการออกแบบสถาปัตยกรรมแอปพลิเคชัน

## Amazon Web Services คืออะไร

AWS เป็นแพลตฟอร์มคลาวด์ที่มีลักษณะเด่นคือ:

- มี **global data centers** กระจายอยู่ทั่วโลก
- มีบริการมากกว่า **200 services**
- มีความปลอดภัยและความน่าเชื่อถือสูง (secure and robust)
- รูปแบบการจ่ายเงินแบบ **pay as you go** (จ่ายตามการใช้งานจริง)
- ออกแบบมาเพื่อรองรับความต้องการทางธุรกิจ (built for business needs)

## ประโยชน์ของการใช้ AWS Services (Why customers move to AWS)

การใช้ AWS services ช่วยเพิ่มความคล่องตัว (agility) และลดความซับซ้อน/ความเสี่ยง (complexity and risk) ผ่านประโยชน์หลัก 6 ข้อ:

1. **Accelerate time to market** — ออกสู่ตลาดได้เร็วขึ้น
2. **Increase innovation** — เพิ่มขีดความสามารถด้านนวัตกรรม
3. **Scale seamlessly** — ขยายขนาดระบบได้อย่างราบรื่น
4. **Optimize costs** — บริหารต้นทุนให้เหมาะสม
5. **Minimize security vulnerabilities** — ลดช่องโหว่ด้านความปลอดภัย
6. **Reduce management complexity** — ลดความซับซ้อนในการบริหารจัดการ

## หมวดหมู่บริการของ AWS (AWS Service Categories)

AWS มีผลิตภัณฑ์คลาวด์ระดับโลกที่หลากหลาย ครอบคลุมหมวดหมู่หลัก ๆ ได้แก่ **compute, storage, database, analytics, networking, mobile, developer tools, management tools, Internet of Things (IoT), security** และ **enterprise applications** บริการเหล่านี้ช่วยให้องค์กรทำงานได้เร็วขึ้น ขยายระบบได้ง่ายขึ้น และลดต้นทุนด้าน IT โดย AWS ครอบคลุมทั้งระดับ infrastructure, foundation และ application services

ในคอร์สนี้จะมีการแนะนำบริการทั้ง 9 หมวดหมู่ (แสดงเป็นไอคอนสี ๆ ในบทเรียน) ซึ่งสอดคล้องกับรายการหมวดหมู่ข้างต้น เช่น compute, networking, database, security, management, storage, enterprise applications และ IoT

หลังจากเข้าใจภาพรวมของ AWS services แล้ว บทเรียนถัดไปจะพาไปรู้จักกับ **AWS infrastructure** ที่ใช้รองรับการโฮสต์แอปพลิเคชัน

## Key terms
- Compute: บริการด้านการประมวลผล เช่น Amazon EC2
- Storage: บริการจัดเก็บข้อมูล เช่น Amazon S3
- Database: บริการฐานข้อมูล
- Analytics: บริการวิเคราะห์ข้อมูล
- Networking: บริการด้านเครือข่าย
- Developer tools: เครื่องมือสำหรับนักพัฒนา
- Management tools: เครื่องมือบริหารจัดการทรัพยากร
- Internet of Things (IoT): บริการสำหรับอุปกรณ์ IoT
- Enterprise applications: แอปพลิเคชันระดับองค์กร
- Pay as you go: รูปแบบการคิดค่าบริการตามการใช้งานจริง ไม่ต้องลงทุนล่วงหน้า
