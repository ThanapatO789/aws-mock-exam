# Knowledge Check

แบบทดสอบท้ายโมดูล ใช้ทบทวนความเข้าใจเนื้อหาทั้งหมดของโมดูล 1 (Architecting Fundamentals) ผลลัพธ์ที่ได้จะช่วยชี้ให้เห็นหัวข้อที่ควรกลับไปทบทวนเพิ่มเติม ประกอบด้วยคำถามแบบปรนัย 5 ข้อ ดังนี้ (คำตอบที่ถูกต้องยืนยันจากระบบหลังตอบจริง)

## คำถามที่ 1

**คำถาม:** ข้อใดคือตัวอย่างที่ดีที่สุดของความรับผิดชอบข้อหนึ่งของ AWS architect
(Which of the following is the BEST example of one responsibility of an AWS architect?)

- Monitor alarms for disaster response.
- Maintain application-level code in the AWS Cloud.
- Manage access to a group of AWS accounts.
- **Analyze solutions for business needs and requirements.** ✅ (คำตอบที่ถูกต้อง)

## คำถามที่ 2

**คำถาม:** ข้อใดคือกลุ่มของ data center ภายในพื้นที่ทางภูมิศาสตร์เดียวกัน ที่เชื่อมต่อเครือข่ายกันด้วย latency ต่ำ
(Which of the following is a cluster of data centers within a geographic location with low latency network connectivity?)

- **Availability Zone** ✅ (คำตอบที่ถูกต้อง)
- Region
- Edge location
- AWS Outposts

## คำถามที่ 3

**คำถาม:** ปัจจัยใดบ้างที่ควรพิจารณาเมื่อเลือก AWS Region (เลือก 2 ข้อ)
(Which of the following factors do you consider when picking an AWS Region? Select TWO.)

- **Local data regulations** ✅ (คำตอบที่ถูกต้อง)
- Operating system requirements
- **Latency to end users** ✅ (คำตอบที่ถูกต้อง)
- Support for hybrid networking
- Programming language of your application

## คำถามที่ 4

**คำถาม:** ประโยชน์หลักของการนำแอปพลิเคชันไปติดตั้งใน Availability Zone หลายแห่งคืออะไร
(What is the primary benefit of deploying your applications into multiple Availability Zones?)

- Stronger security policies for resources
- Decreased latency to resources
- **High availability for resources** ✅ (คำตอบที่ถูกต้อง)
- There is no benefit to this design

## คำถามที่ 5

**คำถาม:** หลักการ "least privilege" (ให้สิทธิ์เท่าที่จำเป็น) อยู่ภายใต้เสาหลักใดของ Well-Architected Framework
(The principle of least privilege is a principle under which Well-Architected Framework pillar?)

- Operational excellence
- **Security** ✅ (คำตอบที่ถูกต้อง)
- Resilience
- Performance efficiency

หลังจากทำแบบทดสอบเสร็จ จะมีวิดีโอสรุปท้ายโมดูลความยาวประมาณ 7 นาที ก่อนเข้าสู่การฝึกปฏิบัติจริงด้วย AWS Labs

## Key terms
- Knowledge Check: แบบทดสอบสั้น ๆ ท้ายโมดูลเพื่อประเมินความเข้าใจ
- AWS Outposts: บริการที่นำโครงสร้างพื้นฐานและบริการของ AWS ไปติดตั้งใช้งาน on-premises (เป็นหนึ่งในตัวเลือกข้อสอบที่ไม่ใช่คำตอบที่ถูกในข้อ 2)
