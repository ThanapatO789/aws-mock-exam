# Overview

โมดูลนี้เป็นบทนำสู่พื้นฐานการออกแบบสถาปัตยกรรม (architecting) แอปพลิเคชันบน AWS โดยเริ่มต้นจากโจทย์ทางธุรกิจ (business request) ของลูกค้าสมมติ แล้วตลอดทั้งโมดูลจะพูดถึงวิธีต่าง ๆ ในการตอบโจทย์ทางธุรกิจนั้นด้วยบริการและแนวทางของ AWS

ในโมดูลนี้ผู้เรียนจะได้เรียนรู้วิธี:

- ใช้ **AWS services** ต่าง ๆ ในการออกแบบสถาปัตยกรรมแอปพลิเคชัน
- ใช้ **AWS infrastructure** (โครงสร้างพื้นฐานทั่วโลกของ AWS) ในแอปพลิเคชัน
- ใช้ **Well-Architected Framework** เพื่อสร้างแอปพลิเคชันบน AWS infrastructure ให้ได้มาตรฐานที่ดี

โมดูลนี้แบ่งเป็น 5 บทเรียนย่อย ได้แก่ Overview, AWS Services, AWS Infrastructure, Well-Architected Framework และ Knowledge Check

## Key terms
- Architecting: กระบวนการออกแบบโครงสร้างและองค์ประกอบของระบบ/แอปพลิเคชันบนคลาวด์
- Business request: โจทย์หรือความต้องการทางธุรกิจที่เป็นจุดเริ่มต้นของการออกแบบสถาปัตยกรรม
- Well-Architected Framework: ชุดแนวทางปฏิบัติที่ดี (best practices) ของ AWS สำหรับประเมินและออกแบบสถาปัตยกรรมระบบคลาวด์
