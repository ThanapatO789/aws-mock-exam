# Database Services

นอกจาก compute และ storage แล้ว database ก็เป็นองค์ประกอบสำคัญของแอปพลิเคชันเช่นกัน บทเรียนนี้ช่วยให้ผู้เรียนสามารถประเมิน (evaluate) เลือกฐานข้อมูลให้เหมาะกับความต้องการของแอปพลิเคชัน

เนื้อหาหลักนำเสนอผ่านวิดีโอผู้สอน (ความยาว 6 นาที) หัวข้อ "Database services" ตั้งคำถามนำว่า "What are the AWS database solutions?"

> หมายเหตุการเก็บเนื้อหา: หน้าบทเรียนนี้มีเนื้อหาข้อความสรุปต่อจากวิดีโอ (ตามรูปแบบที่คอร์สนี้ใช้เสมอ) แต่ระบบของหน้าเว็บมีบั๊กที่ทำให้การเลื่อนหน้าจอ (scroll) ภายใน module viewer พาออกนอกบทเรียนไปยังหน้าอื่นโดยไม่ตั้งใจทุกครั้งที่ลอง จึงไม่สามารถอ่านเนื้อหาส่วนที่อยู่ใต้วิดีโอได้อย่างปลอดภัยในการรันครั้งนี้ เก็บได้เฉพาะย่อหน้าเปิดเรื่องเท่านั้น

## Key terms
- Relational database: ฐานข้อมูลเชิงสัมพันธ์ (มีโครงสร้างตาราง มี schema ตายตัว)
- Non-relational (NoSQL) database: ฐานข้อมูลที่ไม่ใช้โครงสร้างตารางแบบตายตัว
