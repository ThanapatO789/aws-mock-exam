# Knowledge Check

ใช้ Knowledge Check นี้เพื่อทบทวนแนวคิดจากโมดูลนี้ ผลลัพธ์อาจช่วยระบุหัวข้อที่ควรทบทวนเพิ่มเติม (คำตอบที่ถูกต้องยืนยันจากระบบหลังตอบจริงในเบราว์เซอร์)

## คำถามที่ 1

**คำถาม (EN):** Which disaster recovery model offers an RTO in minutes at the lowest cost?

**คำแปล:** โมเดล disaster recovery แบบใดที่ให้ RTO ในระดับนาทีด้วยต้นทุนต่ำที่สุด

ตัวเลือก:
- Fully working low-capacity standby
- **Pilot light** ✅ ถูกต้อง
- Backup and restore
- Multi-site active/active

## คำถามที่ 2

**คำถาม (EN):** Which metrics define how often data must be backed up?

**คำแปล:** เมตริกใดที่กำหนดว่าต้อง backup ข้อมูลบ่อยแค่ไหน

ตัวเลือก:
- RTO
- **RPO** ✅ ถูกต้อง
- Available storage
- Amount of data

## คำถามที่ 3

**คำถาม (EN):** Which of the following are features of AWS Backup? (Select THREE.)

**คำแปล:** ข้อใดต่อไปนี้เป็นคุณสมบัติของ AWS Backup (เลือก 3 ข้อ)

ตัวเลือก:
- **Encrypted backups** ✅ ถูกต้อง
- Works across every AWS service
- **Works across multiple services** ✅ ถูกต้อง
- Automated failover to read replicas
- **Incremental backups** ✅ ถูกต้อง
- Automated machine conversion

## คำถามที่ 4

**คำถาม (EN):** What is the best way to make an existing Amazon RDS DB instance highly available and minimize your RTO?

**คำแปล:** วิธีใดดีที่สุดในการทำให้ Amazon RDS DB instance ที่มีอยู่แล้วมีความพร้อมใช้งานสูง (highly available) และลด RTO ให้น้อยที่สุด

ตัวเลือก:
- Run a secondary copy of your DB instance in another Region.
- **Run a Multi-AZ DB instance in the same Region.** ✅ ถูกต้อง
- Create a read replica in another Region.
- Create a read replica in the same Region.

ผลลัพธ์: ตอบถูกทั้ง 4 ข้อ (ยืนยันโดยการ submit จริงในเบราว์เซอร์)

หลังจากทำแบบทดสอบเสร็จ จะมีวิดีโอสั้น ๆ (ความยาวประมาณ 6 นาที 30 วินาที) ปิดท้ายโมดูล
