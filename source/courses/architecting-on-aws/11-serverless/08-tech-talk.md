# Tech Talk

เนื้อหาหลักนำเสนอผ่านวิดีโอผู้สอน (ความยาว 5 นาที 10 วินาที) เป็นการพูดคุยทบทวนภาพรวมของ serverless architecture ที่ครอบคลุมในโมดูลนี้

หลังจากบทเรียนนี้ ผู้เรียนจะทำ Knowledge Check เพื่อประเมินหัวข้อที่ครอบคลุมในโมดูล จากนั้นทำแล็บเพื่อนำแนวคิดที่เรียนมาไปปฏิบัติจริง

## Key terms
- Tech Talk: บทเรียนสรุปแบบ discussion โดยผู้สอน ทบทวนเนื้อหาของโมดูลก่อนเข้าสู่ Knowledge Check
