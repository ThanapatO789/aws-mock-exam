# Overview

โมดูลนี้แนะนำบริการจัดเก็บข้อมูล (storage services) ต่าง ๆ ที่ AWS มีให้ พร้อมสถานการณ์การใช้งานจริง (use case) ที่ช่วยให้เลือกบริการจัดเก็บข้อมูลที่เหมาะสมกับความต้องการของแอปพลิเคชันได้

ในโมดูลนี้ คุณจะได้เรียนรู้วิธี:

- เปรียบเทียบผลิตภัณฑ์และบริการจัดเก็บข้อมูลของ AWS ตามสถานการณ์ทางธุรกิจ
- เลือกโซลูชันจัดเก็บข้อมูลแบบ object storage ของ **Amazon Simple Storage Service (Amazon S3)** ที่เหมาะสมกับ use case
- เลือกโซลูชันจัดเก็บข้อมูลแบบ shared file system ที่เหมาะสมกับ use case
- ระบุเครื่องมือ AWS Data migration tools ที่เหมาะสม

## Key terms
- Amazon S3: บริการจัดเก็บข้อมูลแบบ object storage ของ AWS
- Shared file system: ระบบไฟล์ที่ใช้งานร่วมกันได้จากหลายเครื่อง/instance
- Data migration tools: เครื่องมือสำหรับย้ายข้อมูลเข้า/ออกจาก AWS
