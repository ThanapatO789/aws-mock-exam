# Knowledge Check

ใช้ Knowledge Check นี้เพื่อทบทวนแนวคิดจากโมดูลนี้ ผลลัพธ์อาจช่วยระบุหัวข้อที่ควรทบทวนเพิ่มเติม

## คำถามที่ 1

**คำถาม (EN):** Which of the following Amazon S3 features would you use to automatically copy new objects to a bucket in a different AWS Region?

**คำแปล:** ฟีเจอร์ใดของ Amazon S3 ที่ใช้คัดลอก object ใหม่ไปยัง bucket ใน AWS Region อื่นโดยอัตโนมัติ

ตัวเลือก:
- Same-Region Replication (SRR)
- Amazon S3 Versioning
- AWS DataSync
- **Cross-Region Replication (CRR)** ✅ ถูกต้อง

## คำถามที่ 2

**คำถาม (EN):** Which Amazon S3 feature can initiate an action to occur after an event takes place within a bucket?

**คำแปล:** ฟีเจอร์ใดของ Amazon S3 ที่สามารถเริ่มการทำงานบางอย่างหลังจากมีเหตุการณ์เกิดขึ้นภายใน bucket

ตัวเลือก:
- Invoking
- **Event notification** ✅ ถูกต้อง
- Lambda
- Alarm

## คำถามที่ 3

**คำถาม (EN):** You have two Linux applications in different Availability Zones that must share a common file system. Which of the following is the BEST solution for this use case?

**คำแปล:** มีแอปพลิเคชัน Linux สองตัวอยู่คนละ Availability Zone ที่ต้องใช้ file system ร่วมกัน ตัวเลือกใดเหมาะสมที่สุดสำหรับ use case นี้

ตัวเลือก:
- Storage Gateway
- FSx for Windows File Server
- Amazon S3
- **Amazon EFS** ✅ ถูกต้อง

## คำถามที่ 4

**คำถาม (EN):** Which of the following are modes available in the Storage Gateway appliance? (Select THREE.)

**คำแปล:** ข้อใดต่อไปนี้เป็นโหมดที่มีอยู่ใน Storage Gateway appliance (เลือก 3 ข้อ)

ตัวเลือก:
- Internet Gateway
- **Tape Gateway** ✅ ถูกต้อง
- **Volume Gateway** ✅ ถูกต้อง
- Virtual Gateway
- **Amazon S3 File Gateway** ✅ ถูกต้อง
- NAT Gateway

ผลลัพธ์: ตอบถูกทั้ง 4 ข้อ (ยืนยันโดยการ submit จริงในเบราว์เซอร์)
