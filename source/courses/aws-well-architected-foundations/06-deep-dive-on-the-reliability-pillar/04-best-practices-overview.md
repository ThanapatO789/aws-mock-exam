# Reliability Best Practices — Overview

## Reliability Best Practices (1.8)
สไลด์เกริ่นนำเข้าสู่หัวข้อ **best practices** ของ reliability pillar

## Reliability best practice areas (1.9)
Reliability pillar มี best practice areas ทั้งหมด **4 ด้าน**:
- **Foundations**
- **Workload architecture**
- **Change management**
- **Failure management**

(สไลด์แสดงเป็นหัวข้อ 4 ด้านเท่านั้น ไม่มีคำอธิบายเพิ่มเติมในข้อมูลดิบที่ดึงมาได้ — รายละเอียดของแต่ละด้านอยู่ในบทเรียนถัดไป)

## Key terms
- Best practice area: กลุ่มของแนวปฏิบัติที่ดีที่สุดภายใต้แต่ละ pillar ของ AWS Well-Architected Framework
