# Learning objectives

ในโมดูลนี้ คุณจะได้เรียนรู้วิธีการ:

- ดำเนินการ Well-Architected Framework Review ให้สำเร็จ (Complete a Well-Architected Framework Review)
- เข้าใจผลกระทบของการตัดสินใจด้านการออกแบบที่มีต่อสถาปัตยกรรมของคุณ (Understand the impact of design decisions about your architecture)
- ประเมินความเสี่ยงในสถาปัตยกรรมของคุณ และวิธีลดความเสี่ยงเหล่านั้น (Evaluate risks in your architecture and how to mitigate them)

## Key terms
- Design decisions: การตัดสินใจเชิงสถาปัตยกรรมที่ส่งผลต่อคุณภาพและความเสี่ยงของ workload
- Mitigate: การลดผลกระทบหรือความน่าจะเป็นของความเสี่ยง
