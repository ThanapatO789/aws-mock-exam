# A mechanism

## A mechanism for continuous improvement

Well-Architected Framework Review เป็น **กลไกสำหรับการปรับปรุงอย่างต่อเนื่อง (continuous improvement)** โดยมีวงจรการทำงานสามขั้นตอนที่หมุนวนรอบ ๆ **Workloads** ตรงกลาง:

- **Learn** — เรียนรู้แนวปฏิบัติที่ดีจากการรีวิว
- **Measure** — วัดผลสถานะปัจจุบันของ workload เทียบกับแนวปฏิบัติที่ดี
- **Improve** — ปรับปรุง workload ตามสิ่งที่พบจากการวัดผล

วงจรนี้หมุนต่อเนื่องไม่รู้จบ สื่อถึงว่าการทำ Well-Architected Review ไม่ใช่กิจกรรมที่ทำครั้งเดียวจบ แต่เป็นกระบวนการที่ควรทำซ้ำอย่างสม่ำเสมอเพื่อพัฒนา workload ให้ดีขึ้นเรื่อย ๆ

## Key terms
- Learn / Measure / Improve: สามขั้นตอนของวงจรกลไกการปรับปรุงต่อเนื่องที่ใช้ในการรีวิว
- Workload: ชุดของทรัพยากรและโค้ดที่ทำงานร่วมกันเพื่อส่งมอบคุณค่าทางธุรกิจ ซึ่งเป็นศูนย์กลางของวงจรนี้
