# Intent of a review

สไลด์นี้อธิบายเจตนารมณ์ที่แท้จริงของ Well-Architected Framework Review ผ่าน 3 ประเด็นสำคัญที่ **ไม่ใช่** ความหมายของการรีวิว:

- **Not an audit** (ไม่ใช่การตรวจสอบ/ออดิต) → เจตนารมณ์ที่แท้จริงคือ **การทำงานร่วมกันเพื่อปรับปรุง (Working together to improve)** ไม่ใช่การจับผิดหรือให้คะแนนผ่าน/ไม่ผ่าน
- **Not theoretical** (ไม่ใช่เรื่องทฤษฎี) → เป็น **คำแนะนำเชิงปฏิบัติที่ผ่านการพิสูจน์แล้ว (Pragmatic, proven advice)** สามารถนำไปใช้ได้จริง
- **Not a one-time check** (ไม่ใช่การตรวจครั้งเดียว) → ควรทำ **ตลอดวงจรชีวิตของ workload (Throughout lifecycle)** ไม่ใช่แค่ก่อนเปิดใช้งาน

## Key terms
- Audit: การตรวจสอบเพื่อประเมินการปฏิบัติตามมาตรฐาน ซึ่งไม่ใช่เป้าหมายของ WAFR
- Lifecycle: วงจรชีวิตของ workload ตั้งแต่ออกแบบ พัฒนา จนถึงดำเนินงานต่อเนื่อง
