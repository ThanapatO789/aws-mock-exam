# Improve

สไลด์หัวข้อ (section divider) — เริ่มต้นหัวข้อย่อยของ **ระยะที่ 3: Improve (การปรับปรุง)** ในกระบวนการ Three Phases of Review ซึ่งจะอธิบายวิธีการจัดลำดับความสำคัญของความเสี่ยง (risk prioritization) และขั้นตอนการปรับปรุง workload ในสไลด์ถัดไป

## Key terms
- Improve: ระยะสุดท้ายของการทำ Well-Architected Framework Review ที่เน้นการจัดลำดับความสำคัญและดำเนินการปรับปรุง workload ตามผลการรีวิว
