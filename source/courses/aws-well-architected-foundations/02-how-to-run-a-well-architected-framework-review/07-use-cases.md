# Use cases

สไลด์นี้แสดงกรณีการใช้งาน (use cases) หลัก 3 แบบของ Well-Architected Framework Review:

- **Learning best practices for the cloud** — ใช้เพื่อเรียนรู้แนวปฏิบัติที่ดีสำหรับการทำงานบนคลาวด์
- **Technology governance** — ใช้เป็นกลไกกำกับดูแลด้านเทคโนโลยีขององค์กร
- **Portfolio management** — ใช้ในการบริหารจัดการพอร์ตโฟลิโอของ workload หลาย ๆ ตัวในองค์กร

## Key terms
- Technology governance: การกำกับดูแลมาตรฐานและแนวปฏิบัติด้านเทคโนโลยีในองค์กร
- Portfolio management: การบริหารจัดการกลุ่ม workload/โปรเจกต์หลายรายการในภาพรวม
