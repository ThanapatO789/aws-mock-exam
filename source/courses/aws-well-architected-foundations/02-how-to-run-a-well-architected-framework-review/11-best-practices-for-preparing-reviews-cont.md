# Best practices for preparing reviews (cont.)

ต่อจากสไลด์ก่อนหน้า มีแนวปฏิบัติที่ดีเพิ่มเติมอีก 3 ข้อสำหรับการเตรียมการรีวิว:

- **Determine review type (กำหนดประเภทของการรีวิว)** — เลือกรูปแบบการรีวิวที่เหมาะสมกับ workload และวัตถุประสงค์
- **Gather data (รวบรวมข้อมูล)** — เก็บรวบรวมข้อมูลที่เกี่ยวข้องกับ workload มาเตรียมไว้ล่วงหน้า
- **Schedule session (กำหนดตารางการประชุม)** — จัดตารางเวลาสำหรับการประชุมรีวิวจริง

## Key terms
- Review type: รูปแบบของการรีวิว ซึ่งอาจแตกต่างกันไปตามขนาดและความซับซ้อนของ workload
- Gather data: การเก็บรวบรวมข้อมูลสถาปัตยกรรม เอกสาร และรายละเอียดที่จำเป็นก่อนเริ่มรีวิว
