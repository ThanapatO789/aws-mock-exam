# Best practices for preparing reviews

แนวปฏิบัติที่ดีสำหรับการเตรียมการรีวิว มี 3 ข้อ:

- **Define workload (กำหนดขอบเขต workload)** — ระบุให้ชัดเจนว่า workload ใดที่จะถูกรีวิว
- **Identify core team (ระบุทีมหลัก)** — กำหนดตัวบุคคลที่จะเข้าร่วมเป็นทีมหลักในการรีวิว
- **Hold scoping session (จัดประชุมกำหนดขอบเขต)** — จัดประชุมเพื่อกำหนดขอบเขตและรายละเอียดของการรีวิวร่วมกับผู้เกี่ยวข้อง

## Key terms
- Scoping session: การประชุมเพื่อกำหนดขอบเขต ผู้เข้าร่วม และรายละเอียดของการรีวิวก่อนเริ่มดำเนินการจริง
- Core team: ทีมหลักที่รับผิดชอบและมีความรู้เกี่ยวกับ workload ที่จะถูกรีวิว
