# Best practices for running reviews

แนวปฏิบัติที่ดีสำหรับการดำเนินการรีวิว มี 3 ข้อ:

- **One person moderates... (มีผู้ดำเนินรายการหนึ่งคน)** — ควรมีคนเดียวทำหน้าที่เป็นผู้ดำเนินการประชุม โดย **มีอีกคนหนึ่งจดบันทึก (One person takes notes)**
- **Use tool to record results (ใช้เครื่องมือบันทึกผล)** — บันทึกผลลัพธ์การรีวิวด้วยเครื่องมือ โดย **ให้มีเพียงคนเดียวเท่านั้นที่อัปเดตเครื่องมือ (Only ONE person updates the tool)** เพื่อป้องกันความสับสน
- **Focus on highest priority issues and risks (มุ่งเน้นปัญหาและความเสี่ยงที่มีความสำคัญสูงสุด)** — **ทำให้เรียบง่ายและอยู่ในขอบเขตที่กำหนด (Keep it simple, stay in scope)**

## Key terms
- Moderate: การทำหน้าที่ดำเนินการประชุมให้เป็นไปตามลำดับและเวลาที่กำหนด
- Scope: ขอบเขตของหัวข้อที่ตกลงกันไว้สำหรับการรีวิว ไม่ควรออกนอกขอบเขตนี้ระหว่างประชุม
