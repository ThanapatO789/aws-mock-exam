# Learnings

สไลด์นี้สรุปบทเรียนสำคัญ 3 ข้อเกี่ยวกับการทำ Well-Architected Framework Review:

- **Pre-launch only?** (ทำแค่ก่อนเปิดใช้งานเท่านั้นหรือ?) → **ยิ่งทำเร็วยิ่งดี (Earlier is better)** ควรเริ่มรีวิวตั้งแต่ช่วงต้นของการออกแบบ ไม่ต้องรอจนใกล้ launch
- **Make bad decisions?** (การตัดสินใจที่ไม่ดีเกิดจากอะไร?) → มักเกิดจาก **การตัดสินใจที่ไม่ได้ผ่านการพิจารณาอย่างรอบด้าน (Not considered decisions)**
- **Findings?** (ผลลัพธ์ที่พบจากการรีวิวเป็นอย่างไร?) → **workload ส่วนใหญ่สามารถปรับปรุงให้ดีขึ้นได้ (Most workloads can be improved)**

## Key terms
- Pre-launch: ช่วงเวลาก่อนที่ workload จะถูกนำไปใช้งานจริง
- Findings: ผลการค้นพบจากกระบวนการรีวิว ซึ่งนำไปสู่ข้อเสนอแนะในการปรับปรุง
