# Risk prioritization methodology and considerations

หลังจากรีวิวเสร็จแล้ว ความเสี่ยงที่พบจะถูกจัดลำดับความสำคัญออกเป็น 2 ระดับหลัก โดยใช้สัญลักษณ์ธงสี:

- **HRI = High-risk issues (ปัญหาความเสี่ยงสูง)** — แสดงด้วยธงสีแดง เป็นปัญหาที่ควรได้รับการแก้ไขอย่างเร่งด่วน
- **MRI = Medium-risk issues (ปัญหาความเสี่ยงปานกลาง)** — แสดงด้วยธงสีส้ม/เหลือง เป็นปัญหาที่มีความสำคัญรองลงมาแต่ยังควรได้รับการติดตาม

การจัดระดับความเสี่ยงนี้ช่วยให้ทีมสามารถจัดลำดับความสำคัญในการดำเนินการปรับปรุงได้อย่างเหมาะสม โดยเน้นแก้ไข HRI ก่อนเป็นอันดับแรก

## Key terms
- HRI (High-risk issue): ปัญหาที่มีความเสี่ยงสูง ควรได้รับการแก้ไขโดยเร็วที่สุด
- MRI (Medium-risk issue): ปัญหาที่มีความเสี่ยงระดับปานกลาง ควรได้รับการติดตามและวางแผนแก้ไข
