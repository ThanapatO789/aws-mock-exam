# Three review phases

Well-Architected Framework Review แบ่งออกเป็น 3 ระยะหลัก:

- **Prepare (เตรียมการ)** — ระบุผู้สนับสนุน (Identify sponsors) และกำหนดขอบเขตของ workload (Scope workload)
- **Review (รีวิว)** — ตรวจสอบ workload (Review the workload) และจัดทำรายงาน (Create the report)
- **Improve (ปรับปรุง)** — จัดลำดับความสำคัญของปัญหา (Prioritize issues) และวางแผนแก้ไข (Treatment plan)

ทั้งสามระยะนี้เป็นโครงสร้างหลักที่จะถูกอธิบายในรายละเอียดต่อไปในโมดูลนี้

## Key terms
- Sponsor: ผู้สนับสนุนหรือผู้มีส่วนได้ส่วนเสียหลักที่อนุมัติและสนับสนุนการทำรีวิว
- Treatment plan: แผนการจัดการหรือแก้ไขปัญหาที่พบจากการรีวิว
