# Well-Architected improvement workflow

สไลด์นี้แสดงแผนภาพวงจรการทำงาน (workflow) สำหรับการปรับปรุง workload อย่างต่อเนื่อง เป็นวงจรหมุนเวียน 5 ขั้นตอนรอบโลโก้ AWS Well-Architected ตรงกลาง:

1. **Identify risks, improvement opportunities** — ระบุความเสี่ยงและโอกาสในการปรับปรุง
2. **Understand risks improvement opportunities** — ทำความเข้าใจความเสี่ยงและโอกาสในการปรับปรุงเหล่านั้นอย่างละเอียด
3. **Determine prescriptive solutions** — กำหนดแนวทางแก้ไขที่เป็นรูปธรรม
4. **Prioritize improvements** — จัดลำดับความสำคัญของการปรับปรุง
5. **Implement and track improvements** — ดำเนินการปรับปรุงและติดตามผล

วงจรนี้หมุนต่อเนื่องไม่สิ้นสุด สอดคล้องกับแนวคิด continuous improvement ที่กล่าวถึงตั้งแต่ต้นโมดูล — เมื่อดำเนินการปรับปรุงและติดตามผลเสร็จแล้ว จะวนกลับไปที่การระบุความเสี่ยงใหม่อีกครั้ง

## Key terms
- Prescriptive solutions: แนวทางแก้ไขที่ชัดเจนและนำไปปฏิบัติได้จริง
- Improvement workflow: กระบวนการที่เป็นระบบสำหรับจัดการและดำเนินการปรับปรุง workload อย่างต่อเนื่อง
