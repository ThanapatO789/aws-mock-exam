# Software and Architecture Patterns

## Software and Architecture Patterns (1.14)
สไลด์เกริ่นนำหัวข้อ best practice area ที่สาม: **Software and architecture patterns**

## Software and architecture patterns (1.15)
Best practices ของหัวข้อนี้มี 5 ข้อ:

1. **Optimize software and architecture for asynchronous and scheduled jobs** — ออกแบบ software และ architecture ให้เหมาะกับงานแบบ asynchronous และงานที่ตั้งเวลาไว้
2. **Remove or refactor workload components with low or no use** — ลบหรือปรับปรุงส่วนประกอบของ workload ที่แทบไม่ได้ใช้งานหรือไม่ได้ใช้เลย
3. **Optimize areas of code that consume the most time or resources** — ปรับปรุงส่วนของโค้ดที่ใช้เวลาหรือทรัพยากรมากที่สุด
4. **Optimize impact on customer devices and equipment** — ลดผลกระทบต่ออุปกรณ์ของลูกค้า
5. **Use software patterns and architectures that support data access and storage patterns** — ใช้ software patterns และ architecture ที่สอดคล้องกับรูปแบบการเข้าถึงและจัดเก็บข้อมูล

## Key terms
- Asynchronous job: งานประมวลผลที่ไม่ต้องรอผลลัพธ์ทันที สามารถประมวลผลในภายหลังได้ ช่วยให้ใช้ทรัพยากรได้อย่างมีประสิทธิภาพมากขึ้น
- Refactor: การปรับปรุงโครงสร้างโค้ดโดยไม่เปลี่ยนพฤติกรรมการทำงาน
