# Data Patterns

## Data Patterns (1.16)
สไลด์เกริ่นนำหัวข้อ best practice area ที่สี่: **Data patterns**

## Data patterns (1.17)
Best practices ของหัวข้อนี้มี 8 ข้อ:

1. **Implement a data classification policy** — กำหนดนโยบายการจำแนกประเภทข้อมูล
2. **Use technologies that support data access and storage patterns** — ใช้เทคโนโลยีที่รองรับรูปแบบการเข้าถึงและจัดเก็บข้อมูล
3. **Use policies to manage the lifecycle of your datasets** — ใช้นโยบายจัดการวงจรชีวิตของชุดข้อมูล
4. **Use shared file systems or object storage to access common data** — ใช้ shared file system หรือ object storage เพื่อเข้าถึงข้อมูลที่ใช้ร่วมกัน
5. **Minimize data movement across networks** — ลดการเคลื่อนย้ายข้อมูลข้ามเครือข่ายให้น้อยที่สุด
6. **Remove unneeded or redundant data** — ลบข้อมูลที่ไม่จำเป็นหรือซ้ำซ้อน
7. **Back up data only when difficult to recreate** — สำรองข้อมูลเฉพาะเมื่อสร้างข้อมูลนั้นขึ้นใหม่ได้ยาก
8. **Use elasticity and automation to expand block storage or file system** — ใช้ elasticity และ automation ในการขยาย block storage หรือ file system

## Key terms
- Data classification policy: นโยบายจำแนกประเภทข้อมูลตามความสำคัญ/ความอ่อนไหว เพื่อช่วยกำหนดวิธีจัดเก็บและดูแลข้อมูลอย่างเหมาะสม
- Data lifecycle: วงจรชีวิตของข้อมูลตั้งแต่สร้างจนถึงลบทิ้ง
