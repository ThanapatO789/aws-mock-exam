# Why use the Well-Architected Framework? / A brief history

## Why use the Well-Architected Framework? (1.6)
ประโยชน์หลักของการใช้ framework นี้มี 4 ข้อ (พร้อมไอคอนประกอบ):
- **Build and deploy faster** — สร้างและ deploy ได้เร็วขึ้น
- **Lower or mitigate risks** — ลดหรือบรรเทาความเสี่ยง
- **Make informed decisions** — ตัดสินใจได้อย่างมีข้อมูลรองรับ
- **Learn AWS best practices** — เรียนรู้แนวปฏิบัติที่ดีของ AWS

## A brief history of the Well-Architected Framework (1.7)
เส้นเวลา (timeline) พัฒนาการของ framework ตั้งแต่ปี 2012–2022:

| ปี | เหตุการณ์ |
|---|---|
| 2012 | Well-Architected started (เริ่มต้นโครงการ) |
| 2013 | AWS solutions architects reviews (AWS solutions architect เริ่มทำ review) |
| 2014 | Questions across four pillars (คำถามครอบคลุม 4 pillars) |
| 2015 | Published framework (เผยแพร่ framework อย่างเป็นทางการ) |
| 2016 | Operational excellence pillar (เพิ่ม pillar ด้าน Operational Excellence) |
| 2017 | AWS Partners, lenses (เปิดให้ AWS Partners เข้าร่วม และเริ่มมี lenses) |
| 2018 | Self-service, improvement plans (เพิ่มโหมด self-service และ improvement plans) |
| 2019 | Regional launches (ขยายให้ใช้งานได้ในหลายภูมิภาค) |
| 2020 | Framework update, review owner (ปรับปรุง framework และเพิ่ม review owner) |
| 2021 | Sustainability, more lenses (เพิ่ม pillar Sustainability และ lenses เพิ่มเติม) |
| 2022 | AWS GovCloud, AWS Trusted Advisor (รองรับ AWS GovCloud และเชื่อมกับ AWS Trusted Advisor) |

## Key terms
- Lens: ชุดคำถามและแนวปฏิบัติเฉพาะทาง (เช่น ตาม industry หรือ workload ประเภทต่าง ๆ) ที่เสริมจาก framework หลัก
- AWS Trusted Advisor: บริการที่ช่วยตรวจสอบและแนะนำแนวปฏิบัติที่ดีสำหรับบัญชี AWS
