## What Is the Well-Architected Framework? (1.3)
สไลด์หัวข้อ (section divider) — เกริ่นนำหัวข้อย่อยถัดไปเกี่ยวกับข้อมูลทั่วไปของ framework ประโยชน์ และประวัติความเป็นมา

## Are you Well-Architected? (1.4)
เมื่อมองที่ workload ที่ทีมของคุณกำลังสร้าง คุณสามารถตอบคำถามนี้ได้หรือไม่:

> "Are you Well-Architected?"

Well-Architected Framework ถูกสร้างขึ้นมาเพื่อตอบคำถามนี้ — เป็นชุดหลักการออกแบบและแนวปฏิบัติที่ดี

## What is the Well-Architected Framework? (1.5)
การใช้ framework นี้จะช่วยให้คุณเรียนรู้แนวปฏิบัติที่ดีด้านสถาปัตยกรรม (architectural best practices) สำหรับการออกแบบและดำเนินงานระบบที่:
- **ปลอดภัย (secure)**
- **เชื่อถือได้ (reliable)**
- **มีประสิทธิภาพ (efficient)**
- **คุ้มค่าใช้จ่าย (cost-effective)**
- **ยั่งยืน (sustainable)**

บนคลาวด์ (in the cloud)

แผนภาพประกอบแสดงวงจร **Improve → Learn → Measure** (ปรับปรุง → เรียนรู้ → วัดผล) ที่หมุนวนต่อเนื่อง โดยมี "Other workloads" (workload อื่น ๆ) วนเข้ามาป้อนเข้าสู่วงจรนี้ด้วย — สื่อถึงว่า framework นี้เป็นกระบวนการทำซ้ำ (iterative) ที่นำไปใช้กับ workload ต่าง ๆ อย่างต่อเนื่อง

## Key terms
- Workload: ชุดของทรัพยากรและโค้ดที่ทำงานร่วมกันเพื่อส่งมอบคุณค่าทางธุรกิจ
- Secure / Reliable / Efficient / Cost-effective / Sustainable: 5 คุณสมบัติหลักที่ระบบที่ดีควรมี ตาม framework นี้
