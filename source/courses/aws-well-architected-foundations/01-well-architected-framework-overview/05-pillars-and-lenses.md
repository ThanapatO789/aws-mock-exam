# Pillars of AWS Well-Architected / Well-Architected lenses

## Pillars of AWS Well-Architected (1.11)
Framework ประกอบด้วย 6 pillars (มีไอคอนประกอบแต่ละ pillar):
1. **Operational excellence** — ความเป็นเลิศด้านการปฏิบัติงาน
2. **Security** — ความปลอดภัย
3. **Reliability** — ความเชื่อถือได้
4. **Performance efficiency** — ประสิทธิภาพการทำงาน
5. **Cost optimization** — การปรับให้คุ้มค่าใช้จ่าย
6. **Sustainability** — ความยั่งยืน

## Well-Architected lenses (1.12)
Lens คือชุดคำถาม/แนวปฏิบัติเฉพาะทางที่ต่อยอดจาก framework หลัก โดยมีตัวอย่าง lens ต่าง ๆ แสดงเป็นรังผึ้ง (honeycomb) บนสไลด์ ได้แก่:
- Data Analytics Lens
- Games Industry Lens
- Machine Learning Lens
- Financial Services Industry Lens
- Serverless Application Lens
- IoT Lens
- Custom Lenses (ไฮไลต์สีเหลืองตรงกลาง — ผู้ใช้สามารถสร้าง lens ของตนเองได้)
- Hybrid Networking Lens
- SAP Lens
- Streaming Media Lens
- SaaS Lens
- HPC Lens (High Performance Computing)

## Key terms
- Lens: ชุดคำถามและแนวปฏิบัติเสริมเฉพาะอุตสาหกรรม/ประเภท workload ที่ใช้ควบคู่กับ pillars หลัก
- Custom Lens: lens ที่องค์กรสร้างขึ้นเองให้เหมาะกับบริบทของตน
