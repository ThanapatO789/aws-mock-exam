## Components of the Well-Architected Framework (1.9)
แผนภาพ Venn diagram แสดง 3 องค์ประกอบหลักที่ทับซ้อนกัน: **Content**, **Tool**, **Data** (มีจุดตัดร่วมตรงกลางเป็นโลโก้ AWS Well-Architected)

- **Content** เชื่อมโยงกับ:
  - Helpful resources: Content summaries, Inline glossary (สรุปเนื้อหา, อภิธานศัพท์ในตัว)
  - Framework: Pillars (areas), Design principles, Questions, Best practices
  - Whitepapers (PDF, Kindle), Training, Website

- **Tool** เชื่อมโยงกับ:
  - Workloads: Review (Q&A), Dashboard, Report (PDF)
  - Document workloads: Description, Regions, Pillar priority

- **Data** เชื่อมโยงกับ:
  - Review approach: Self-service, Partner, AWS led
  - Resources from partners: APN, Marketplace
  - Improvement plans
  - Review: Rating, Answers, Notes, Milestones

## Well-Architected Framework content (1.10)
เนื้อหาของ framework แบ่งเป็น 4 ส่วนหลัก (มีไอคอนประกอบแต่ละส่วน):
- **Pillars and lenses** — เสาหลักและเลนส์
- **Design principles** — หลักการออกแบบ
- **Questions** — คำถามสำหรับ review
- **Best practices** — แนวปฏิบัติที่ดี

## Key terms
- Improvement plan: แผนปรับปรุงที่ได้จากผลการ review workload เทียบกับ best practices
- Review owner: ผู้รับผิดชอบดูแลกระบวนการ review ของ workload
