# Security Pillar Overview

## Security Pillar Overview (1.3)
สไลด์เกริ่นนำ: ต่อไปผู้เรียนจะได้ภาพรวมของ security pillar

## Pillars of Well-Architected (1.4)
ปัจจุบัน AWS Well-Architected Framework มีทั้งหมด **6 pillars**:

- Operational excellence
- Security
- Reliability
- Performance efficiency
- Cost optimization
- Sustainability

pillars ทั้งหมดนี้เป็นรากฐาน (foundations) ของสถาปัตยกรรมสำหรับ technology solutions บน cloud โมดูลนี้จะเน้นที่ **security pillar**

## What is the security pillar? (1.5)
**Security pillar** ครอบคลุมความสามารถในการปกป้อง data, systems และ assets บน cloud การจะ operate workload ได้อย่างปลอดภัย ต้องนำ best practices ไปประยุกต์ใช้กับทุกพื้นที่ของ security (overarching best practices)

## Key terms
- Security pillar: ความสามารถในการปกป้อง data, systems และ assets บน cloud
- Pillar: หนึ่งในหมวดหมู่หลัก (6 หมวด) ของ AWS Well-Architected Framework
