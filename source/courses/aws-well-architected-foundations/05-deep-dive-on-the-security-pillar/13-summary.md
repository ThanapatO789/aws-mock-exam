# Summary / Thank you

## Summary (1.35)
ในโมดูลนี้ ผู้เรียนได้เรียนรู้เกี่ยวกับ **security pillar** เริ่มตั้งแต่ภาพรวม (overview) และครอบคลุมการอภิปรายเชิงลึกเรื่อง value proposition, design principles และ best practices ของ security pillar

## Thank you (1.36)

## Key terms
- Security pillar: pillar ของ AWS Well-Architected Framework ที่เน้นการปกป้อง data, systems และ assets บน cloud ผ่าน 7 best practice areas: Security Foundations, Identity and Access Management, Detection, Infrastructure Protection, Data Protection, Incident Response, Application Security
