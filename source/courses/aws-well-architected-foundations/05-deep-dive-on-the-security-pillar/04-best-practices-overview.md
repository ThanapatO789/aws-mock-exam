# Security Best Practices — Overview

## Security Best Practices (1.8)
สไลด์เกริ่นนำ: ต่อไปผู้เรียนจะได้เรียนรู้ security best practices

## Security — 7 best practice areas (1.9)
security pillar แบ่งออกเป็น **7 best practice areas**:

1. Security Foundations
2. Identity and Access Management
3. Detection
4. Infrastructure Protection
5. Data Protection
6. Incident Response
7. Application Security

## Key terms
- Best practice area: กลุ่มหัวข้อ best practices ย่อยภายใต้แต่ละ pillar
