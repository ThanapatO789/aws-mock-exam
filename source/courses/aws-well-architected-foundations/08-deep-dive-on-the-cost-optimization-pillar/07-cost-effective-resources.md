# Cost-Effective Resources

## Cost-Effective Resources (1.16)
สไลด์คั่นเข้าสู่หัวข้อ best practice area ที่สาม: Cost-Effective Resources

## Evaluate cost when selecting services (1.17)
แนวปฏิบัติเมื่อประเมินต้นทุนในการเลือกใช้บริการ:
- **Identify organization requirements for cost** — ระบุความต้องการด้านต้นทุนขององค์กร
- **Analyze all workload components** — วิเคราะห์ทุก component ของ workload
- **Select software with cost-effective licensing** — เลือก software ที่มี licensing แบบคุ้มค่า
- **Select components to optimize cost in line with organization priorities** — เลือก component ให้สอดคล้องกับความสำคัญทางธุรกิจ
- **Perform thorough analysis of each component** — วิเคราะห์แต่ละ component อย่างละเอียด
- **Perform cost analysis for different usage over time** — วิเคราะห์ต้นทุนตามรูปแบบการใช้งานที่เปลี่ยนแปลงไปตามเวลา

## Select correct resource type, size, and number (1.18)
- **Perform cost modeling** — จำลองต้นทุนล่วงหน้า
- **Select resource type, size, and number based on data** — เลือกประเภท ขนาด และจำนวน resource จากข้อมูลจริง
- **Select resource type, size, and number automatically based on metrics** — เลือกโดยอัตโนมัติตาม metrics

## Select pricing model (1.19)
- **Perform pricing model analysis** — วิเคราะห์รูปแบบราคา
- **Implement Regions based on cost** — เลือก Region ตามต้นทุน
- **Implement pricing models for all components of a workload** — ใช้รูปแบบราคาที่เหมาะสมกับทุก component
- **Perform pricing model analysis at the management account level** — วิเคราะห์รูปแบบราคาระดับ management account
- **Select third-party agreements with cost-efficient terms** — เลือกข้อตกลงกับบุคคลที่สามที่มีเงื่อนไขคุ้มค่า

## Plan for data transfer (1.20)
- **Perform data transfer modeling** — จำลองการถ่ายโอนข้อมูล
- **Select components to optimize data transfer cost** — เลือก component เพื่อลดต้นทุนการถ่ายโอนข้อมูล
- **Select services to reduce data transfer costs** — เลือกบริการที่ช่วยลดต้นทุนการถ่ายโอนข้อมูล

## Key terms
- Pricing model: รูปแบบการคิดราคาของ AWS เช่น On-Demand, Reserved, Savings Plans, Spot
- Data transfer cost: ต้นทุนที่เกิดจากการถ่ายโอนข้อมูลเข้า/ออกหรือระหว่าง service
