# Welcome! / Learning objectives

## Welcome! (1.1)
สไลด์เปิดโมดูล 3: "AWS Well-Architected — Deep Dive on the AWS Well-Architected Tool" พร้อมคำบรรยาย (narration): ยินดีต้อนรับเข้าสู่โมดูลที่ 3 ของซีรีส์ AWS Well-Architected ซึ่งเป็นการเจาะลึก (deep dive) เรื่อง AWS Well-Architected Tool

## Learning objectives (1.2)
ในโมดูลนี้ผู้เรียนจะได้เรียนรู้:
- องค์ประกอบและฟีเจอร์ต่าง ๆ ของ **AWS Well-Architected Tool** (เรียกย่อว่า AWS WA Tool)
- วิธีใช้ tool เพื่อทำ **Well-Architected Framework Review**
- แหล่งข้อมูลเพิ่มเติมเกี่ยวกับ AWS WA Tool

## Key terms
- AWS Well-Architected Tool (AWS WA Tool): เครื่องมือใน AWS Management Console สำหรับ review workload เทียบกับ AWS Well-Architected Framework
- Framework Review: กระบวนการตรวจสอบ workload เทียบกับ best practices ของ framework
