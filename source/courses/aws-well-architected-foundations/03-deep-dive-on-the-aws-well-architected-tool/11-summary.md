# Summary / Thank you

## Summary (1.20)
สรุปสิ่งที่ได้เรียนรู้ในโมดูลนี้:
- องค์ประกอบและฟีเจอร์ต่าง ๆ ของ **AWS Well-Architected Tool**
- วิธีใช้ AWS Well-Architected Tool เพื่อทำ **Well-Architected Framework Review**
- แหล่งข้อมูลเพิ่มเติมเกี่ยวกับ AWS Well-Architected Tool

(narration เสริม): ในโมดูลนี้ ผู้เรียนได้เรียนรู้เกี่ยวกับ AWS Well-Architected Tool โดยเฉพาะองค์ประกอบและฟีเจอร์ของ tool และวิธีใช้ทำ Framework Review รวมถึงได้รู้ว่าจะไปหาข้อมูลเพิ่มเติมเกี่ยวกับ AWS Well-Architected Tool ได้จากที่ไหน

## Thank you (1.21)
ขอบคุณที่สละเวลาเรียนรู้เกี่ยวกับ AWS WA Tool — ขอแนะนำให้พิจารณาโมดูลการเรียนรู้อื่น ๆ ต่อไปในเส้นทาง Well-Architected ของคุณ

- หากมีข้อแก้ไข ข้อเสนอแนะ หรือคำถามอื่น ๆ ติดต่อได้ที่ **Training and Certification**
