# Components of the Well-Architected Framework

## Components of the Well-Architected Framework (1.4)
ทบทวนแผนภาพองค์ประกอบของ framework ที่เคยเห็นในโมดูลก่อนหน้า (Venn diagram: **Content**, **Tool**, **Data**):

- **Content** — เนื้อหาที่ใช้เรียนรู้ AWS best practices เช่น helpful resources (content summaries, inline glossary), framework (pillars/areas, design principles, questions, best practices), whitepapers (PDF, Kindle), training, website
- **Tool** — เครื่องมือช่วยวัดผล workload และทีมงานเทียบกับ best practices เช่น workloads (review Q&A, dashboard, report PDF), document workloads (description, regions, pillar priority)
- **Data** — ข้อมูลที่ได้จากการ review workload เช่น review approach (self-service, partner, AWS led), resources from AWS Partner Network (APN) Marketplace, improvement plans, review (rating, answers, notes, milestones)

ข้อมูล (data) เหล่านี้สามารถนำไปใช้ปรับปรุง workload และการดำเนินงานได้อย่างต่อเนื่อง ในโมดูลนี้จะเจาะลึกว่าลูกค้าสามารถใช้ **AWS WA Tool** เพื่อวัดผลและปรับปรุงเมื่อเวลาผ่านไปได้อย่างไร

## Key terms
- Content: เนื้อหา/องค์ความรู้ของ framework
- Tool: เครื่องมือ (AWS WA Tool) สำหรับวัดผล workload
- Data: ข้อมูลที่เก็บระหว่างการ review workload
