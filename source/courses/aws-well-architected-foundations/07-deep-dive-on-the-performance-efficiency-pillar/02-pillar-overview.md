# Performance Efficiency Pillar Overview

## Performance Efficiency Pillar Overview (1.3)
สไลด์เกริ่นนำเข้าสู่ภาพรวมของ performance efficiency pillar

## Pillars of Well-Architected (1.4)
ปัจจุบัน AWS Well-Architected Framework มี **6 pillars**:
- **Operational excellence**
- **Security**
- **Reliability**
- **Performance efficiency**
- **Cost optimization**
- **Sustainability**

Pillars ทั้งหมดนี้เป็นรากฐาน (foundations) ของสถาปัตยกรรมสำหรับ technology solutions บน cloud โมดูลนี้จะเน้นที่ **performance efficiency pillar**

## What is the performance efficiency pillar? (1.5)
**Performance efficiency pillar** เน้นการใช้ computing resources อย่างมีประสิทธิภาพ (efficient) เพื่อตอบสนอง requirements และรักษาประสิทธิภาพไว้ได้แม้ demand จะเปลี่ยนแปลงและเทคโนโลยีมีการพัฒนาไป

สไลด์นี้ยังตั้งคำถามชวนคิดต่อว่า "ทำไม performance efficiency จึงสำคัญต่อการปรับปรุงสถาปัตยกรรม (architecture)" เพื่อนำเข้าสู่หัวข้อ design principles ในบทถัดไป

## Key terms
- Well-Architected Framework: กรอบแนวทางของ AWS ที่ช่วยประเมินและปรับปรุงสถาปัตยกรรม cloud ผ่าน 6 pillars
- Performance efficiency: ประสิทธิภาพในการใช้ resources เพื่อให้ได้ผลลัพธ์ตามที่ต้องการโดยใช้ทรัพยากรอย่างคุ้มค่าที่สุด
