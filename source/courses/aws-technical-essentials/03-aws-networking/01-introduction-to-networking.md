# Introduction to Networking

Networking คือวิธีที่เราเชื่อมต่อคอมพิวเตอร์ทั่วโลกเข้าด้วยกันเพื่อให้สื่อสารกันได้ ตัวอย่างที่เคยเห็นมาแล้วในคอร์สนี้คือ AWS Global Infrastructure ซึ่ง AWS สร้างเครือข่ายของ data centers, Availability Zones และ Regions ขึ้นมา

## แนวคิดพื้นฐานของ Networking

เปรียบเทียบการส่งข้อมูลในเครือข่ายกับการส่งจดหมาย: การส่งจดหมายต้องมี 3 องค์ประกอบ
- ตัวจดหมายที่อยู่ในซองจดหมาย
- ที่อยู่ผู้ส่ง (from)
- ที่อยู่ผู้รับ (to)

แต่ละที่อยู่ต้องมีข้อมูลครบ ได้แก่ ชื่อผู้ส่ง/ผู้รับ, ถนน, เมือง, รัฐ/จังหวัด, รหัสไปรษณีย์, ประเทศ — ถ้าขาดส่วนใดส่วนหนึ่งไปรษณีย์จะส่งจดหมายไม่ถึงปลายทาง ในโลกดิจิทัล คอมพิวเตอร์ก็จัดการส่งข้อความในลักษณะคล้ายกัน เรียกกระบวนการนี้ว่า **routing**

## IP addresses

ในการส่งข้อความไปยังตำแหน่งที่ถูกต้อง จำเป็นต้องมี address เช่นเดียวกับบ้านแต่ละหลังมีที่อยู่ไปรษณีย์ คอมพิวเตอร์แต่ละเครื่องก็มี **IP address** ซึ่งแทนที่จะเป็นชุดของถนน/เมือง/รัฐ/รหัสไปรษณีย์/ประเทศ กลับใช้ชุดของบิต 0 และ 1 แทน

ตัวอย่าง IP address แบบ 32-bit เขียนในรูปแบบ binary — เรียกว่า 32 bit เพราะมีตัวเลข 32 หลัก

## IPv4 notation

โดยทั่วไปเราจะไม่เห็น IP address ในรูปแบบ binary แต่จะถูกแปลงเป็นรูปแบบ decimal และเรียกว่า **IPv4 address**

ใน diagram บิตทั้ง 32 บิตจะถูกแบ่งเป็นกลุ่มละ 8 บิต เรียกว่า **octet** แต่ละกลุ่มจะถูกแปลงเป็นเลขฐาน 10 (decimal) คั่นด้วยจุด (period) เช่น IP address `192.168.1.30` ถูกแปลงมาจากบิต 4 กลุ่ม กลุ่มละ 8 บิต

IPv4 address ใช้สำหรับสื่อสารกับคอมพิวเตอร์เครื่องเดียว แต่เมื่อทำงานกับ "เครือข่าย" (network) จะต้องใช้ **Classless Inter-Domain Routing (CIDR)**

## CIDR notation

`192.168.1.30` คือ IP address เดี่ยวๆ หนึ่งตัว แต่ถ้าต้องการระบุช่วง (range) ของ IP address เช่นระหว่าง `192.168.1.0` ถึง `192.168.1.255` จะใช้ **CIDR notation** ซึ่งเป็นวิธีย่อในการแทนช่วงของ IP address โดยการระบุช่วงจะกำหนดว่ามี IP address ให้ใช้งานได้กี่ตัว

CIDR notation เริ่มต้นด้วย starting IP address ตามด้วยเครื่องหมาย `/` แล้วตามด้วยตัวเลข ตัวเลขท้ายนี้ระบุว่าบิตกี่บิตของ IP address ถูก "fix" ไว้ (ไม่เปลี่ยนแปลง) ตัวอย่างเช่น ถ้า fix 24 บิตแรก บิตที่เหลือ (8 บิตสุดท้าย) จะยืดหยุ่นได้ (flexible)

จากบิตทั้งหมด 32 บิต ลบด้วย 24 บิตที่ fix ไว้ เหลือ 8 บิตที่ flexible แต่ละบิต flexible เลือกได้ 2 ค่า (0 หรือ 1) ดังนั้นจึงมี IP address ในช่วงนั้นทั้งหมด 256 ตัว

ยิ่งตัวเลขหลัง `/` มากขึ้น จำนวน IP address ในเครือข่ายก็ยิ่งน้อยลง เช่น ช่วง `192.168.1.0/24` มีขนาดเล็กกว่า `192.168.1.0/16`

เมื่อทำงานกับเครือข่ายใน AWS Cloud เราเลือกขนาดเครือข่าย (network size) โดยใช้ CIDR notation ใน AWS ช่วง IP ที่เล็กที่สุดที่กำหนดได้คือ **/28** (ให้ 16 IP addresses) และช่วงที่ใหญ่ที่สุดคือ **/16** (ให้ 65,536 IP addresses)

## Key terms
- Routing: กระบวนการนำส่งข้อความ/ข้อมูลไปยังปลายทางที่ถูกต้องในเครือข่าย
- IP address: ที่อยู่ของคอมพิวเตอร์แต่ละเครื่องในเครือข่าย ประกอบด้วยชุดบิต 0/1
- IPv4 address: IP address แบบ 32-bit ที่แสดงในรูปแบบ decimal 4 กลุ่ม (octet) คั่นด้วยจุด
- Octet: กลุ่มของ 8 บิตในที่อยู่ IPv4
- CIDR (Classless Inter-Domain Routing): สัญกรณ์ย่อสำหรับระบุช่วงของ IP address เช่น 192.168.1.0/24
- CIDR block size: ยิ่งเลขหลัง `/` มาก ยิ่งมี IP address น้อยลง; AWS รองรับตั้งแต่ /28 (เล็กสุด, 16 IP) ถึง /16 (ใหญ่สุด, 65,536 IP)
