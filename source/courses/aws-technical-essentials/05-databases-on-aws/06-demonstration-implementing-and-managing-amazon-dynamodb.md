# Demonstration: Implementing and Managing Amazon DynamoDB

บทเรียนนี้เป็นวิดีโอสาธิต (demonstration) เกี่ยวกับการสร้างและจัดการ Amazon DynamoDB โดยระบุไว้ชัดเจนว่าวิดีโอนี้มีไว้เพื่อเป็น **visual walk-through** เท่านั้น ไม่ใช่แบบฝึกหัดแบบลงมือทำเอง (hands-on exercise)

เนื้อหาสาธิตแสดงขั้นตอนการสร้างและจัดการตาราง DynamoDB ผ่าน AWS Management Console (ต่อเนื่องจากตัวอย่างแอป employee directory ที่ใช้ตลอดคอร์สนี้) เพื่อให้เห็นภาพรวมของการทำงานจริงบน console ประกอบความเข้าใจจากบทเรียนก่อนหน้าเกี่ยวกับ Amazon DynamoDB

## Key terms
- Demonstration video: วิดีโอสาธิตที่ AWS จัดทำเพื่อแสดงขั้นตอนการทำงานจริงบน console โดยไม่ต้องลงมือทำตาม
