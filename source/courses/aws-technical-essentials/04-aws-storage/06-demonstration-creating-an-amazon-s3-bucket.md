# Demonstration: Creating an Amazon S3 Bucket

บทเรียนนี้เป็นวิดีโอสาธิต (demonstration) การสร้าง Amazon S3 bucket ซึ่งตั้งใจให้เป็นการดูสาธิตแบบ visual walk-through เท่านั้น ไม่ใช่แบบฝึกหัดที่ต้องลงมือทำตาม (hands-on exercise)

เนื้อหาหลักของบทเรียนอยู่ในวิดีโอสาธิตทั้งหมด โดยหน้าเว็บไม่มีเนื้อหาข้อความเพิ่มเติมนอกจากคำอธิบายสั้นๆ ก่อนวิดีโอ และปุ่มสำหรับขยายดู transcript ของวิดีโอ

## Key terms
- Demonstration lesson: บทเรียนที่นำเสนอเนื้อหาผ่านวิดีโอสาธิตเป็นหลัก แทนที่จะเป็นแบบฝึกหัดลงมือทำ (hands-on lab)
